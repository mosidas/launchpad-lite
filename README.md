# launchpad-lite

Raycast の代わりに使う、最小限の macOS ランチャー。アプリのあいまい検索と起動、ウィンドウ操作、スクリーンショット、スリープをホットキーで行う。外付けマウスのポインタ・ホイール・ボタンも設定できる。Swift(SwiftPM)製で Xcode を必要としない。

## 使い方

[Releases](https://github.com/mosidas/launchpad-lite/releases) から `LaunchpadLite-<バージョン>.zip` をダウンロードして展開し、`LaunchpadLite.app` を `/Applications` へ移して開く。Apple Silicon 向けのビルドである。Dock には出ず、メニューバーにアイコンが出る。

配布物はアドホック署名だけで公証していないため、初回の起動は Gatekeeper に止められる。次のどちらかで起動を許可する。

- ターミナルで `xattr -dr com.apple.quarantine /Applications/LaunchpadLite.app` を実行し、隔離属性を外す。
- 一度開いてブロックされたあと、システム設定 > プライバシーとセキュリティ の下部にある「このまま開く」を押す(macOS 14 では Finder で右クリックして「開く」でもよい)。

ソースからビルドするときは、`scripts/bundle.sh` を実行し、できた `dist/LaunchpadLite.app` を `/Applications` へコピーして開く。

ログイン時に自動で起動するには、メニューバーのアイコンから「ログイン時に起動」を選択する。もう一度選択すると解除する。この切り替えは `.app` から起動したときだけ働き、`swift run` で動かしたときはエラーになる。以前にシステム設定 > 一般 > ログイン項目へ `LaunchpadLite.app` を手で追加していた場合は、二重に起動しないようその項目を削除する。

## ホットキー

キーはメニューバーのアイコンから「設定…」を開いて変える。行のボタンを押してから新しいキーを押すと、その組み合わせを保存し、すぐに有効になる。受け付けるのは ⌘・⌃・⌥ のいずれかを含むキーだけで、Escape を押すと記録を取り消す。「既定に戻す」を押すと、すべてのキーが下の表の既定値に戻る。他のアプリや別の動作と重なって登録できなかったキーには、行に「登録できない」と表示する。

既定のキーには、OS の標準ショートカットと重なるものがある。システム設定 > キーボード > キーボードショートカットで、OS 側の同じショートカットを先に無効にしておく。

- ⌘Space: Spotlight のショートカットを無効にする。
- ⇧⌘3・⇧⌘4: スクリーンショットのショートカットを無効にする。

既定のキーは次のとおりである。

| 既定のキー | 動作 |
| :- | :- |
| ⌘Space | ランチャーを開く・閉じる |
| ⇧⌘S | スクリーンショットのツールバーを開く(⇧⌘5 と同じ) |
| ⇧⌘← / ⇧⌘→ | 左半分 / 右半分 |
| ⇧⌘↑ / ⇧⌘↓ | 上半分 / 下半分 |
| ⇧⌘1 / ⇧⌘2 / ⇧⌘3 / ⇧⌘4 | 右上 1/4 / 左上 1/4 / 左下 1/4 / 右下 1/4 |
| ⇧⌘Return | 最大化 |
| ⇧⌘C | 中央 3/4(幅・高さとも画面の 3/4 にして中央へ移す) |
| ⌃⌘← / ⌃⌘→ | 前 / 次のディスプレイへ移す |
| ⌥⌘S | スリープする |

## マウス

メニューバーのアイコンから「設定…」を開き、「マウス」のタブで設定する。変えた値はすぐに反映され、再起動後も残る。設定の対象は外付けマウスだけで、トラックパッドの動きは変わらない。

設定できる項目は次のとおりである。

| 項目 | 内容 | 既定値 |
| :- | :- | :- |
| ポインタの加速・速度 | ポインタの加速のオン/オフと速度 | システム設定の値 |
| 縦のスクロールを反転する | ホイールの縦スクロールの向きを逆にする | オフ |
| 横のスクロールを反転する | サムホイールなどの横スクロールの向きを逆にする | オン |
| 1 目盛りの行数 | ホイールを 1 目盛り回したときに進む行数(1〜20) | 4 行 |
| ボタンの割り当て | ボタンとサムホイールの左右に、システム操作かキーボードショートカットを割り当てる | サイドボタンに戻る・進む |

ホイールの速度は 1 目盛りの行数で決まる。ゆっくり回しても速く回しても 1 目盛りの量は同じで、OS のスクロール加速は無効になる。

ボタンを割り当てるには、「ボタンを記録」を押してから、カーソルが設定ウィンドウの上にある状態でマウスのボタンを押し、追加された行で動作を選択する。「キーボードショートカット」を選択したときは、続けてキーを押す。修飾キーの無いキーも受け付け、Escape を押すと記録を取り消す。「なし」を選択すると割り当てを外す。サムホイールは、左右に 1 目盛り回すごとに 1 回動作する。

システム操作には次の制約がある。

- 戻る・進むは、Apple 製アプリ(Safari・Finder など)では ⌘[ / ⌘] を送り、他のアプリではマウスの戻る・進むボタン(設定の画面のボタン 4・5)の押下を送る。
- 左右の Space への移動は、システム設定 > キーボード > キーボードショートカットの Mission Control で ⌃← / ⌃→ が有効なときだけ働く。
- macOS 26 では、Launchpad の代わりに「アプリ」が開く。

「既定に戻す」を押すと、すべての項目が既定値に戻り、ポインタはシステム設定の値に戻る。

LinearMouse など、マウスの設定を変える同種のアプリとは併用しない。設定が互いに上書きされる。LaunchpadLite の起動中にシステム設定でマウスの速度を変えても、5 秒以内に LaunchpadLite の設定へ戻る。LaunchpadLite を終了しても、ポインタの設定はマウスを接続し直すまで残る。

## 権限

ウィンドウ操作のため、システム設定 > プライバシーとセキュリティ > アクセシビリティで LaunchpadLite を許可する。この許可は、マウスのイベントの書き換えとキー・ボタンの送出にも使う。許可すると数秒以内にマウスの機能が働く。許可を取り消して再び許可した場合も、数秒以内にマウスの機能が働く。

再ビルドするとアドホック署名が変わり、許可が無効になる。一覧から LaunchpadLite を一度消して追加し直す。`swift run` で動かしたときは、権限は LaunchpadLite ではなく実行したターミナルに付く。

## ビルドとテスト

- ビルド: `scripts/bundle.sh`(release ビルド、`.app` の組み立て、アドホック署名を行う)
- アイコン: `scripts/bundle.sh` が `Resources/AppIcon.png` からビルドのたびに `AppIcon.icns` を作る。
- テスト: `scripts/test.sh`(Command Line Tools だけの環境では `swift test` が swift-testing を見つけられないため、検索パスを付けて呼ぶ)

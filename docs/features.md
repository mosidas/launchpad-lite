# LaunchpadLite の機能と設定

LaunchpadLite の機能ごとに、操作・設定の項目・既定値・制約を説明する。インストールと最初の操作は、[launchpad-lite の README](../README.md) の手順で行う。設定は、メニューバーのアイコンから「設定…」を開いて行う。

## ログイン時の起動

ログイン時に自動で起動するには、メニューバーのアイコンから「ログイン時に起動」を選択する。もう一度選択すると解除する。この切り替えは `.app` から起動したときだけ働き、`swift run` で動かしたときはエラーになる。以前にシステム設定 > 一般 > ログイン項目へ `LaunchpadLite.app` を手で追加していた場合は、二重に起動しないようその項目を削除する。

## ランチャー

ランチャーでは、アプリを英語名と Finder の表示名(例: システム設定)のどちらでも検索できる。

3 文字以上の入力では、1 文字の打ち間違い(例: 「safrai」で Safari)でもアプリが見つかる。正しく一致したアプリは、打ち間違いで見つかったアプリより先に出る。

一致の良さが同じアプリどうしでは、最近起動したアプリとよく起動するアプリが上に出る。何も入力していないときは、よく使うアプリから順に並ぶ。起動の履歴はこの Mac の中にだけ保存する。

検索の対象は、/Applications・/System/Applications・~/Applications のすべてのアプリと、/System/Library/CoreServices にある Finder などの利用者が開くアプリである。CoreServices の常駐のヘルパーは対象にしない。

アプリの追加・削除は、次にランチャーを開いたときに反映される。

一覧の各行には、アプリ名の左にアプリのアイコンを出す。

## ホットキー

メニューバーのアイコンから「設定…」を開き、「ホットキー」のページで変える。行のボタンを押してから新しいキーを押すと、その組み合わせを保存し、すぐに有効になる。受け付けるのは ⌘・⌃・⌥ のいずれかを含むキーだけで、Escape を押すと記録を取り消す。「既定に戻す」を押すと、すべてのキーが下の表の既定値に戻る。他のアプリや別の動作と重なって登録できなかったキーには、行に「登録できない」と表示する。

既定のキーには、OS の標準ショートカットと重なるものがある。システム設定 > キーボード > キーボードショートカットで、OS 側の同じショートカットを先に無効にしておく。

- ⌘Space: Spotlight のショートカットを無効にする。
- ⇧⌘3・⇧⌘4: スクリーンショットのショートカットを無効にする。

既定のキーは次のとおりである。

| 既定のキー | 動作 |
| :- | :- |
| ⌘Space | ランチャーを開く・閉じる |
| ⇧⌘S | スクリーンショットのツールバーを開く(⇧⌘5 と同じ) |
| ⇧⌘7 | 範囲を撮って画面に浮かべる(「スクリーンショット」の節) |
| ⇧⌘← / ⇧⌘→ | 左半分 / 右半分 |
| ⇧⌘↑ / ⇧⌘↓ | 上半分 / 下半分 |
| ⇧⌘1 / ⇧⌘2 / ⇧⌘3 / ⇧⌘4 | 右上 1/4 / 左上 1/4 / 左下 1/4 / 右下 1/4 |
| ⇧⌘Return | 最大化 |
| ⇧⌘C | 中央 3/4(幅・高さとも画面の 3/4 にして中央へ移す) |
| ⌃⌘← / ⌃⌘→ | 前 / 次のディスプレイへ移す |
| ⌥⌘S | スリープする |

## スクリーンショット

⇧⌘7 を押すと、OS の範囲選択が始まる。ドラッグで範囲を選択すると、選択した位置に撮った画像が最前面で浮かぶ。範囲選択の途中で Space キーを押してウィンドウ単位の撮影に切り替えると、画像はカーソルの位置を中心に出る。Escape を押すと撮影を取り消す。

浮かべた画像はファイルに残らず、閉じると消える。残すには ⌘S で PNG に保存する。

浮かべた画像は次の操作で扱う。

| 操作 | 結果 |
| :- | :- |
| ドラッグ | 画像を動かす。動かしている間は移動中の不透明度まで薄くなる(ホイールでそれより下げていれば下げたまま) |
| ホイール | 不透明度を 10〜100% の間で変える |
| ⌘+ / ⌘- | 拡大 / 縮小(25〜250%、25% 刻み) |
| ⌘0 | 元の位置と大きさに戻す |
| ⌘C | 画像をコピーする |
| ⌘S | 画像を PNG で保存する |
| ⌘W・Escape・ダブルクリック | 画像を閉じる |
| 右クリック | 上と同じ操作と、表示する Space の切り替えをメニューから選ぶ |

メニューバーのアイコンから「設定…」を開き、「スクリーンショット」のページで次の 2 項目を設定する。表示する Space は新しく浮かべる画像に適用され、浮かべ済みの画像は変わらない(浮かべ済みの画像では右クリックのメニューで切り替える)。移動中の不透明度は、浮かべ済みの画像にも次のドラッグから適用される。

| 項目 | 内容 | 既定値 |
| :- | :- | :- |
| 移動中の不透明度 | ドラッグで動かしている間の不透明度 | 70% |
| 表示する Space | 画像をすべての Space に出すか、浮かべたときの Space だけに出すか | すべての Space |

範囲の撮影には画面収録の許可が必要である(「権限」の節)。

## マウス

メニューバーのアイコンから「設定…」を開き、「マウス」のページで設定する。変えた値はすぐに反映され、再起動後も残る。設定の対象は外付けマウスだけで、トラックパッドの動きは変わらない。

設定できる項目は次のとおりである。

| 項目 | 内容 | 既定値 |
| :- | :- | :- |
| ポインタの加速・速度 | ポインタの加速のオン/オフと速度 | システム設定の値 |
| 縦のスクロールを反転する | ホイールの縦スクロールの向きを逆にする | オフ |
| 横のスクロールを反転する | サムホイールなどの横スクロールの向きを逆にする | オン |
| 1 目盛りの行数 | ホイールを 1 目盛り回したときに進む行数(1〜20) | 4 行 |
| ボタンの割り当て | ボタンとサムホイールの左右に、システム操作かキーボードショートカットを割り当てる | サイドボタンに戻る・進む |

ホイールの速度は 1 目盛りの行数で決まる。ゆっくり回しても速く回しても 1 目盛りの量は同じで、OS のスクロール加速は無効になる。

ボタンを割り当てるには、「ボタンを記録」を押してから、カーソルが設定ウィンドウの上にある状態でマウスのボタンを押し、追加された行で動作を選択する。「キーボードショートカット」を選択したときは、続けてキーを押す。修飾キーの無いキーも受け付け、Escape を押すと記録を取り消す。「なし」を選択すると割り当てを外す。サムホイールは、左右に 1 目盛り回すごとに 1 回動作する。

システム操作には次の制約がある。

- 戻る・進むは、Apple 製アプリ(Safari・Finder など)では ⌘[ / ⌘] を送り、他のアプリではマウスの戻る・進むボタン(設定の画面のボタン 4・5)の押下を送る。
- 左右の Space への移動は、システム設定 > キーボード > キーボードショートカットの Mission Control で ⌃← / ⌃→ が有効なときだけ働く。
- macOS 26 では、Launchpad の代わりに「アプリ」が開く。

「既定に戻す」を押すと、すべての項目が既定値に戻り、ポインタはシステム設定の値に戻る。

LinearMouse など、マウスの設定を変える同種のアプリとは併用しない。設定が互いに上書きされる。LaunchpadLite の起動中にシステム設定でマウスの速度を変えても、5 秒以内に LaunchpadLite の設定へ戻る。LaunchpadLite を終了しても、ポインタの設定はマウスを接続し直すまで残る。

## キーボード

メニューバーのアイコンから「設定…」を開き、「キーボード」のページで設定する。変えた値はすぐに反映され、再起動後も残る。

F1〜F12 の各行で動作を選択すると、そのキーを押したときに、キー本来の入力の代わりにシステム操作かキーボードショートカットを実行する。システム操作の一覧と制約はマウスのボタンの割り当てと同じである。「キーボードショートカット」を選択したときは、続けてキーを押す。修飾キーの無いキーも受け付け、Escape を押すと記録を取り消す。「なし」を選択すると割り当てを外す。押しっぱなしにしても、動作は 1 回だけ起きる。

- 置き換えるのは修飾キーの無い F キーだけである。⌘・⌃・⌥・⇧ のいずれかを押しながら押した F キーは、元のまま届く。
- Apple 製キーボードでは、F キーが既定で輝度・音量などの特殊機能を送る。システム設定 > キーボードの「F1、F2 などのキーを標準のファンクションキーとして使用」を有効にするか、fn を押しながら F キーを押す。

### キーの置き換え

「キーの置き換え」の節で、任意のキーを別のキーに置き換える。「キーを追加」を押し、元のキー、置き換え先のキーの順に押す。Caps Lock・左右の修飾キー(⌘・⌃・⌥・⇧)・Escape も押せる。記録を取り消すには、記録中のボタン(「元のキーを入力…」など)をもう一度押す。置き換え先を変えるには行のボタンを押してからキーを押し、置き換えを外すには「削除」を押す。Caps Lock を元のキーとして記録したときは、記録のために押して点いたロックを記録の終了時に消す。

- 置き換えは接続中のすべてのキーボードに適用される。後から接続したキーボードにも 5 秒以内に適用される。
- LaunchpadLite を終了すると、置き換えは解除される。
- Karabiner-Elements や `hidutil` と併用しない。キーの置き換えの設定が互いに上書きされる。
- fn(地球儀)キーは置き換えの対象外である。

「既定に戻す」を押すと、F キーの割り当てとキーの置き換えをすべて外す。

## 権限

ウィンドウ操作のため、システム設定 > プライバシーとセキュリティ > アクセシビリティで LaunchpadLite を許可する。この許可は、マウスとキーボードのイベントの書き換えとキー・ボタンの送出にも使う。許可すると数秒以内にマウスとキーボードの機能が働く。許可を取り消して再び許可した場合も、数秒以内にマウスとキーボードの機能が働く。

範囲を撮って浮かべる機能(⇧⌘7)には、システム設定 > プライバシーとセキュリティ > 画面収録で LaunchpadLite を許可する。許可したら LaunchpadLite を開き直す。開き直すまで許可は有効にならない。
